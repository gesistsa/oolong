# Print oolong gold standard object

This function prints a summary of the oolong gold standard object. An
oolong gold standard object is a result of \$turn_gold() method. It is a
quanteda::corpus compatible object.

## Usage

``` r
# S3 method for class 'oolong_gold_standard'
print(x, ...)
```

## Arguments

- x:

  an oolong gold standard object

- ...:

  other parameters

## Value

None, a summary of the quanteda::corpus and what you should do are
displayed
